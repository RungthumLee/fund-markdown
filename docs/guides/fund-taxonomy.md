# 🏷️ Fund Taxonomy — ตารางรหัสทั้งหมด

รวมรหัส (enum) ทุกตัวที่ใช้ในชุดข้อมูลกองทุน พร้อมความหมาย
ใช้คู่กับ [[fund-identifiers|Fund Identifiers]] และ [[../api-reference/02-fund-profiles|Fund Profiles API]]

**ที่เกี่ยวข้อง:** [[scope-and-filters|เกณฑ์การคัดกรองของโปรเจกต์นี้]] · [[data-dictionary|Data Dictionary]]

---

## `fund_status` — สถานะกองทุน

| รหัส | ความหมาย | นับเป็น "ยังมีอยู่"? |
|---|---|---|
| `Registered` | จดทะเบียนกองทุนแล้ว — เปิดดำเนินการอยู่ | ✅ **ใช่** |
| `IPO` | อยู่ระหว่างเสนอขายครั้งแรก | ⚠️ ยังไม่จัดตั้ง |
| `Expired` | หมดเวลาเสนอขาย (ไม่ได้จัดตั้ง) | ❌ |
| `Canceled` | เลิกโครงการ | ❌ |
| `Liquidated` | จดทะเบียนเลิกกองทุน | ❌ |

> โปรเจกต์นี้เก็บเฉพาะ `Registered` — ดู [[scope-and-filters|Scope & Filters]]

## `proj_retail_type` — ลักษณะโครงการ / กลุ่มผู้ลงทุน

| รหัส | ความหมาย | จำนวน (share class) |
|---|---|---|
| `R` | กองทุนเพื่อผู้ลงทุนทั่วไป (retail) | 4,651 |
| `X` | เสนอขายผู้ลงทุนสถาบันและผู้ลงทุนรายใหญ่พิเศษ (UI) | 159 |
| `V` | **กองทุนรวมเพื่อผู้ลงทุนที่เป็นกองทุนสำรองเลี้ยงชีพ (PVD)** | 29 |
| `B` | เสนอขายเฉพาะผู้มีเงินลงทุนสูง (HNW) | 22 |
| `A` | เสนอขายเฉพาะผู้ลงทุนที่มิใช่รายย่อย (AI) | 12 |
| `H` | เสนอขายผู้ลงทุนที่มิใช่รายย่อยและผู้มีเงินลงทุนสูง | 12 |
| `N` | กองทุนเพื่อผู้ลงทุนสถาบัน (II) | 5 |
| `G` | กองทุนรวมพิเศษเพื่อตอบสนองนโยบายภาครัฐ | 2 |
| `F` | กองทุนรวมเสริมสภาพคล่องตลาดตราสารหนี้ภาคเอกชน | 0 |

> [!IMPORTANT]
> `V` = **PVD** — โปรเจกต์นี้ **ตัดออก** ตามที่กำหนดขอบเขต

## `proj_term_flag` — อายุโครงการ

| รหัส | ความหมาย |
|---|---|
| `Y` | **กำหนดอายุโครงการ** → คือ **Term Fund** (กองทุนกำหนดอายุ) |
| `N` | ไม่กำหนดอายุโครงการ (open-end ทั่วไป) |

อายุระบุแยกเป็น `proj_term_year` / `proj_term_month` / `proj_term_day`

> [!IMPORTANT]
> `proj_term_flag = Y` = **Term Fund** — โปรเจกต์นี้ **ตัดออก**

---

## `policy_desc` — ประเภทกองทุนตามนโยบายการลงทุน

| ค่า | คำอธิบาย |
|---|---|
| `ตราสารทุน` | Equity fund |
| `ผสม` | Mixed / Allocation fund |
| `ตราสารหนี้` | Fixed income fund |
| `ทรัพย์สินทางเลือก` | Alternative assets (ทอง, น้ำมัน, REIT, infra) |
| `อื่น ๆ` | Other |
| `ไม่ระบุ เนื่องจากเป็นกองทุนรวมอีทีเอฟแบบ leveraged / inverse` | ETF พิเศษ |

---

## `management_style` — กลยุทธ์การบริหาร

| รหัส | ความหมาย |
|---|---|
| `AM` | Active — มุ่งให้ผลประกอบการสูงกว่าดัชนีชี้วัด |
| `AN` | Feeder — กองหลัก active |
| `PM` | Passive / index tracking |
| `PN` | Feeder — กองหลัก passive |
| `IM` | Inverse — เคลื่อนไหวตรงข้ามดัชนีรายวัน |
| `IN` | Feeder — กองหลัก inverse |
| `LM` | Leveraged — ทวีคูณผลตอบแทนรายวันของดัชนี |
| `LN` | Feeder — กองหลัก leveraged |
| `BH` | Buy-and-hold — ลงทุนครั้งเดียว |
| `SM` | Enhanced index — ตามดัชนี แต่บางโอกาสอาจสูงกว่า |
| `OT` | อื่น ๆ |

> `AN` / `PN` / `IN` / `LN` = **Feeder Fund** — ดูกองหลักที่ field `feederfund_master_fund`
> และประเทศที่ `feederfund_country`

## `invest_country_flag` — ความเสี่ยงต่างประเทศ

| รหัส | ความหมาย |
|---|---|
| `1` | เน้นลงทุนต่างประเทศ |
| `2` | ลงทุนในต่างประเทศบางส่วน |
| `3` | ไม่มีความเสี่ยงต่างประเทศ (ลงทุนในไทยล้วน) |
| `4` | มีความเสี่ยงทั้งในและต่างประเทศ |

## `fund_class_tax_incentive_type` — สิทธิประโยชน์ทางภาษี

| ค่า | ความหมาย |
|---|---|
| `กองทุนรวมเพื่อการออม (Super Savings Fund : SSF)` | SSF |
| `กองทุนรวมไทยเพื่อความยั่งยืน (Thailand ESG Fund : Thai ESG)` | Thai ESG |
| `""` (ว่าง) | ไม่มีสิทธิประโยชน์พิเศษ / RMF ระบุผ่านชื่อกองทุน |

## `entity_type` — บุคคล/นิติบุคคลที่เกี่ยวข้อง

ใช้ใน [[../api-reference/05-involve-parties|Involve Parties API]]

| รหัส | ความหมาย |
|---|---|
| `A` | ผู้สอบบัญชี (Auditor) |
| `U` | ผู้จัดจำหน่าย (Underwriter) |
| `S` | ผู้สนับสนุนการขายและรับซื้อคืน (Selling agent) |
| `R` | นายทะเบียนหน่วยลงทุน (Registrar) |
| `V` | ผู้ดูแลผลประโยชน์ (Trustee / Custodian) |
| `M` | ที่ปรึกษาการลงทุน (Investment advisor) |
| `O` | ผู้รับมอบหมายงานด้านการจัดการลงทุน (Sub-manager) |
| `P` | ผู้ลงทุนรายใหญ่ |
| `K` | ผู้ดูแลสภาพคล่อง (Market maker) |
| `N` | ที่ปรึกษาทางการเงิน |
| `F` | ผู้จัดการกองทุน (Fund manager) |

## `prospectus_type` — ประเภทการส่ง Factsheet

| รหัส | ความหมาย |
|---|---|
| `IPO` | ส่งตอนยื่นขอจัดตั้งกองทุน |
| `Monthly` | ส่งรายเดือน (ใช้เป็นข้อมูลหลัก) |
| `SignificantFactsheet` | ส่งเมื่อมีการเปลี่ยนแปลงอย่างมีนัยสำคัญ |

## `fee_type_desc` — ประเภทค่าธรรมเนียม

ใช้ใน [[../api-reference/14-factsheet-fees|Factsheet Fees]] และ [[../api-reference/04-mutual-fund-fees|Mutual Fund Fees]]

| ค่า | ความหมาย | เก็บจากใคร |
|---|---|---|
| `Front-end Fee` | ค่าธรรมเนียมการขายหน่วยลงทุน | ผู้ลงทุน (ตอนซื้อ) |
| `Back-end Fee` | ค่าธรรมเนียมการรับซื้อคืนหน่วยลงทุน | ผู้ลงทุน (ตอนขาย) |
| `Switching In` | ค่าธรรมเนียมสับเปลี่ยนเข้า | ผู้ลงทุน |
| `Switching Out` | ค่าธรรมเนียมสับเปลี่ยนออก | ผู้ลงทุน |
| `Transfer Fee` | ค่าธรรมเนียมการโอนหน่วยลงทุน | ผู้ลงทุน |
| `Management Fee` | ค่าธรรมเนียมการจัดการ | กองทุน |
| `Total Fee and Expense` | ค่าธรรมเนียมและค่าใช้จ่ายรวม (TER) | กองทุน |

> [!NOTE]
> ค่าธรรมเนียมมี 2 ชั้น — เก็บจาก **กองทุน** (Management Fee, TER) กับเก็บจาก
> **ผู้ลงทุน** (Front-end, Back-end) อย่าเอามารวมกันตรง ๆ
> `rate` = อัตราสูงสุดตามโครงการ, `actual_value` = อัตราที่เก็บจริง

## `risk_spectrum` — ระดับความเสี่ยง (1–8)

| ระดับ | ประเภทสินทรัพย์โดยทั่วไป |
|---|---|
| 1 | กองทุนตลาดเงินในประเทศ |
| 2 | กองทุนตลาดเงินที่ลงทุนต่างประเทศบางส่วน |
| 3 | กองทุนพันธบัตรรัฐบาล |
| 4 | กองทุนตราสารหนี้ทั่วไป |
| 5 | กองทุนผสม |
| 6 | กองทุนตราสารทุน |
| 7 | กองทุนหมวดอุตสาหกรรม (sector fund) |
| 8 | กองทุนสินทรัพย์ทางเลือก (ทอง น้ำมัน อนุพันธ์) |

ค่าจริงอยู่ใน field `risk_spectrum` และคำอธิบายที่ `risk_spectrum_desc`
ดู [[../api-reference/11-risk-spectrum|Risk Spectrum API]]
