# 📦 ข้อมูล Holdings — พอร์ตการลงทุนของกองทุน

**ที่เกี่ยวข้อง:** [[factsheet-extraction|Factsheet Extraction]] · [[fund-identifiers|Fund Identifiers]] · [[../api-reference/18-outstanding-portfolio|API: Portfolio]] · [[../api-reference/17-top5-holdings|API: Top 5]]

---

## ข้อมูล holdings มาจาก 5 แหล่ง — คนละความละเอียด

| แหล่ง | ระดับความละเอียด | ความถี่ | ที่มา |
|---|---|---|---|
| `out_portfolio` | **รายหลักทรัพย์ ทุกตัว** | รายไตรมาส | API |
| `out_port_asset_type` | รวมตามประเภทสินทรัพย์ | รายเดือน | API |
| `fs_top5` | 5 อันดับแรก | รายเดือน | API |
| `fs_asset_alloc` | รวมตามประเภทสินทรัพย์ | รายเดือน | API |
| Factsheet PDF | **กลุ่มอุตสาหกรรม / ประเทศ / credit rating** | รายเดือน | PDF |

> [!IMPORTANT]
> ไม่มีแหล่งไหนแทนกันได้ทั้งหมด — `out_portfolio` ละเอียดที่สุดแต่ช้าที่สุด (รายไตรมาส)
> ส่วน factsheet ให้มิติที่ API ไม่มีเลย (sector / country / rating)

## 1. `out_portfolio` — พอร์ตรายตัวแบบเต็ม

**ละเอียดที่สุด** — ทุกหลักทรัพย์ที่กองถือ พร้อม ISIN และผู้ออก

| Field | ความหมาย |
|---|---|
| `period` | งวด `YYYYMM` |
| `as_of_date` | วันที่ข้อมูล |
| `assetliab_id` / `assetliab_desc` | รหัส/ชื่อประเภทสินทรัพย์ |
| `issue_code` | ชื่อย่อหลักทรัพย์ |
| `isin_code` | ISIN |
| `issuer` | ผู้ออกตราสาร |
| `assetliab_value` | มูลค่า (บาท) |
| `percent_nav` | สัดส่วนต่อ NAV |

โปรเจกต์นี้เก็บ **ทุกรายการของงวดล่าสุด** ไม่ตัดทอน
(เดิมเคยจำกัด 30 อันดับ — ยกเลิกแล้ว)

พร้อมคำนวณเพิ่ม:

| ค่าที่คำนวณ | ความหมาย |
|---|---|
| `total_rows` | จำนวนหลักทรัพย์ที่ถือ |
| `issuer_count` | จำนวนผู้ออกที่ไม่ซ้ำ — วัดการกระจายความเสี่ยงเครดิต |
| `top10_pct_nav` | น้ำหนัก 10 อันดับแรกรวม (% ของ NAV) |
| `top10_share_of_port` | 10 อันดับแรกคิดเป็นกี่ % ของพอร์ต |

`top10_pct_nav` ใช้วัด **ความกระจุกตัว** — ค่าสูงแปลว่าผลตอบแทนของกองผูกกับ
หลักทรัพย์ไม่กี่ตัว query ได้จาก frontmatter:

````
```dataview
TABLE holdings_count, top10_pct_nav
FROM #fund
WHERE top10_pct_nav > 60
SORT top10_pct_nav DESC
```
````

> [!WARNING]
> **ข้อมูลรายไตรมาสจึงล้าหลัง** — งวดล่าสุดอาจเก่ากว่า NAV หลายเดือน
> ดูวันที่ใน `as_of_date` ที่แสดงกำกับตารางในโน้ตเสมอ

### ⚠️ สองเรื่องที่ทำให้ตัวเลขดูผิด แต่จริง ๆ ถูก

**1. แถวสรุปที่ต้องตัดออก**

`assetliab_id = 903` คือแถว **"มูลค่าทรัพย์สินสุทธิ"** ซึ่งเป็นยอดรวม
ไม่ใช่รายการที่ถือ และมีค่า 100% ของ NAV เสมอ
ถ้านับรวมจะทำให้ตัวเลขกระจุกตัวของทุกกอง **สูงเกินจริงเท่าตัว**

`transform.py` ตัดแถวนี้ออกจาก holdings แล้วนำค่าไปใช้เป็น
`net_asset_value` (ขนาดกองทุน) แทน — ใช้กับ `out_port_asset_type` ด้วย
(รหัส 903 = `รวม = sum(101-599) หัก sum(601-699)`)

**2. น้ำหนักรวมเกิน 100% เป็นเรื่องปกติ**

ตัวอย่าง K-ASIAX: หน่วยลงทุนกองหลัก 103.4% + เงินฝาก 16.2% = เกิน 100%

เพราะตารางแสดง **ฐานะขั้นต้น (gross)** ซึ่งถูกหักกลบด้วย
รายการหนี้สินที่มีค่า **ติดลบ** ในตารางเดียวกัน
**ไม่ใช่** การใช้ leverage — โน้ตกองทุนจะขึ้นคำเตือนอัตโนมัติเมื่อเจอกรณีนี้

## 2. `out_port_asset_type` — สัดส่วนตามประเภทสินทรัพย์

รายเดือน จึงใหม่กว่า `out_portfolio` แต่ไม่บอกว่าถือตัวไหน
เหมาะกับการดูภาพรวมว่ากองถือหุ้น/ตราสารหนี้/เงินฝาก อย่างละเท่าไร

## 3. `fs_top5` — 5 อันดับแรก

มาจาก factsheet โดยตรง อัปเดตรายเดือน
ใช้ตรวจสอบว่า `out_portfolio` (ที่เก่ากว่า) ยังสอดคล้องอยู่หรือไม่

## 4. `fs_asset_alloc` — การจัดสรรตาม factsheet

คล้าย `out_port_asset_type` แต่มาจาก factsheet
ตัวเลขอาจต่างกันเล็กน้อยเพราะวันที่อ้างอิงไม่ตรงกัน

## 5. Factsheet PDF — มิติที่ API ไม่มี

- **กลุ่มอุตสาหกรรม (sector)** — สำคัญมากสำหรับกองหุ้น
- **ประเทศ / ภูมิภาค** — สำหรับกองต่างประเทศ
- **อันดับความน่าเชื่อถือ** — สำหรับกองตราสารหนี้
- **Holdings ของกองทุนหลัก** — look-through ของ [[../../vault/Concepts/Feeder Fund|feeder fund]]

วิธีแกะอยู่ที่ [[factsheet-extraction|Factsheet Extraction]]

## Feeder fund — ต้องอ่าน 2 ชั้น

> [!IMPORTANT]
> พอร์ตของ feeder fund จาก API จะแสดงเป็น **หน่วยลงทุนของกองทุนหลัก ~100%**
> ซึ่งถูกต้องแต่ไม่มีประโยชน์ในการวิเคราะห์
>
> ```
> พอร์ตจาก API      : JPM US Growth I (acc) — 101.06% ของ NAV
> look-through จาก PDF: Alphabet 9.7% · Nvidia 9.1% · Apple 5.5% · ...
> ```
>
> โน้ตกองทุนจึงแสดง **ทั้งสองชั้น** โดยแยกหัวข้อชัดเจน
> ตารางที่มีคำว่า "ของกองทุนหลัก" คือ look-through

## ตำแหน่งในโน้ตกองทุน

หัวข้อ **7. พอร์ตการลงทุน** เรียงจากภาพรวมไปละเอียด:

1. การจัดสรรสินทรัพย์ (จาก factsheet API)
2. 5 อันดับแรกที่ลงทุน
3. สัดส่วนตามประเภทสินทรัพย์ (รายเดือน)
4. **รายการลงทุนรายตัวทั้งหมด** (รายไตรมาส) — พร้อมสถิติกระจุกตัว
5. **ข้อมูลเพิ่มเติมจาก Factsheet** — sector / country / rating / look-through

ตารางที่ยาวเกิน 25 แถวจะถูกพับไว้ใน `<details>` เพื่อให้โน้ตยังอ่านง่าย

```bash

data/raw/out_portfolio.jsonl

```
