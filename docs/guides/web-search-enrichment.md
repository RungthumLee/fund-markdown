# 🔎 เก็บข้อมูลกองทุนหลักด้วยการค้นเว็บ

**ที่เกี่ยวข้อง:** [[master-fund-sources|Yahoo + FT]] · [[../project/issues|Issues]] ·
[[../project/decisions|Decisions]] · [[../project/roadmap|Roadmap]]

หลัง Yahoo + FT ทำงานจบ ยังมีกองทุนหลักส่วนหนึ่งที่ไม่มีข้อมูลเลย
เอกสารนี้อธิบายว่าใช้ **ผลค้นเว็บ / AI Overview** มาเติมได้แค่ไหน และ**ห้าม**ใช้ตรงไหน

---

## ข้อสรุปสั้น ๆ

> [!IMPORTANT]
> ผลค้นเว็บมีค่าในฐานะ **ตัวหา ISIN** ไม่ใช่ในฐานะ **แหล่งตัวเลข**

เมื่อได้ ISIN แล้ว ตัวเลขจริงมาจาก FT/Yahoo ซึ่งเป็นแหล่งที่ pipeline
ตรวจสอบได้ซ้ำและอ้างอิง share class ได้ถูกต้อง

---

## ทำไมถึงไม่เอาตัวเลขจากผลค้นมาใส่ตรง ๆ

ทดสอบกับ **GMO Quality Investment Fund**

| | ค่าธรรมเนียม | ขนาดกองทุน |
|---|---|---|
| สรุปจากผลค้นเว็บ | 1.05% | 7.8bn USD |
| FT (share class `IE00B3SBSR82`) | **0.53%** | **6.61bn GBP** |

ไม่ใช่ว่าผลค้นผิดทั้งหมด — แต่มัน**ปนตัวเลขข้าม share class**
กอง UCITS หนึ่งกองมี 10–30 share class ค่าธรรมเนียมต่างกันได้ 3 เท่า
และ**กองทุนหลักของกองไทยเป็น share class เฉพาะเจาะจงเสมอ**

ถ้าเก็บดิบ ๆ ตารางเทียบค่าธรรมเนียมจะจัดอันดับผิด ซึ่งเป็นความผิดพลาดแบบเดียวกับ
[[../project/issues|ISS-009]] ที่เคยเจอกับค่า `0.0` ของ Yahoo

## ขั้นตอนที่ใช้จริง

```
scripts/search_masters.py queue      →  รายการที่ยังขาด + query ที่ควรค้น
        ↓  (ค้นเว็บ)
   found.json                        →  ISIN ที่เจอ + prose + แหล่งอ้างอิง
        ↓
scripts/search_masters.py ingest     →  ยืนยัน ISIN กับ FT (USD/EUR/GBP) + Yahoo
        ↓                                ยืนยันไม่ได้ = ทิ้ง ไม่บันทึก
   data/masters/<key>.json
```

รูปแบบ `found.json`

```json
{"name:fermat ucits cat bond": {
   "isin":  ["IE000SV333V4", "IE000N9XFSD0"],
   "facts": {"management_fee": "1.50% ต่อปี"},
   "note":  "คำอธิบายเชิงบรรยาย",
   "sources": ["https://..."]}}
```

| field | ปลายทาง | ใช้ในตารางเปรียบเทียบ |
|---|---|---|
| `isin` | ยืนยันกับ FT/Yahoo ก่อน ถ้าผ่านจึงกลายเป็นข้อมูลปกติ | ✅ ใช้ |
| `facts` | เก็บเฉพาะเมื่อ**ยืนยัน ISIN ไม่ได้** แสดงในบล็อกแยก | ❌ ไม่ใช้ |
| `note` | prose ในบล็อกแยก | ❌ ไม่ใช้ |
| `sources` | ลิงก์อ้างอิงท้ายบล็อก | — |

ISIN ที่ยืนยันไม่ได้ถูกบันทึกไว้ที่ `search_isin_rejected` เพื่อไม่ให้ค้นซ้ำ

## สิ่งที่แสดงในโน้ต

โน้ตที่มีข้อมูลแบบยังไม่ยืนยันจะมีหัวข้อ **🔎 ข้อมูลจากการค้นเว็บ (ยังไม่ยืนยัน)**
พร้อมกล่อง `[!CAUTION]` อยู่บนสุดของโน้ต และติด tag `#web-search`

ค้นทั้งหมดได้ด้วย Dataview

````

```
````

## ผลที่ได้จริง

| | |
|---|---|
| ค้นแล้ว | 19 กอง |
| **ยืนยัน ISIN ได้ → ข้อมูลจริง** | **12** |
| ได้เฉพาะข้อมูลยังไม่ยืนยัน | 4 |
| ค้นไม่เจออะไรที่ใช้ได้ | 3 |

กองที่ยืนยันไม่ได้มักเป็นกองที่ไม่มีตลาดรองจริง ๆ —
private credit / BDC feeder (Ares, Apollo, Blackstone iCapital),
กองเฮดจ์ฟันด์ Cayman และกองที่ขายเฉพาะในมาเลเซีย/สิงคโปร์

> [!NOTE]
> เครื่องมือที่ใช้เป็น **web search** ไม่ใช่การอ่านกล่อง AI Overview ของ Google โดยตรง
> (Google บล็อกการ scrape SERP — ดู [[../project/issues|ISS-001]] ซึ่งเป็นอาการเดียวกัน)
> แต่ได้ผลลัพธ์แบบเดียวกันคือ ลิงก์ + บทสรุปที่สังเคราะห์จากลิงก์เหล่านั้น
> ข้อจำกัดเรื่องปน share class เป็นของบทสรุปทั้งสองแบบเหมือนกัน

## หมายเหตุเรื่อง pipeline

`search_masters.py` **ไม่ได้อยู่ใน `run_all.py`** เพราะขั้นตอนค้นเว็บต้องมีคนหรือ agent
อยู่ในลูป — สคริปต์ทำได้แค่สองฝั่ง (สร้าง queue และยืนยันผล) ส่วนตรงกลางเป็นการค้นจริง
รันเมื่อต้องการเก็บตกเท่านั้น ผลที่ ingest แล้วจะอยู่ใน `data/masters/` ถาวร
และ `gen_master_notes.py` หยิบไปใช้ในรอบถัดไปเอง
