# 🎯 กลยุทธ์การบริหารกองทุน (Management Style)

## รหัสทั้งหมด

| รหัส | กลยุทธ์ | เป้าหมาย |
|---|---|---|
| `AM` | **Active** | ทำผลตอบแทน **สูงกว่า** ดัชนีชี้วัด |
| `PM` | **Passive / Index tracking** | เคลื่อนไหว **ตาม** ดัชนีชี้วัด |
| `SM` | **Enhanced index** | ตามดัชนี แต่บางโอกาสอาจสูงกว่า |
| `BH` | **Buy-and-hold** | ลงทุนครั้งเดียวแล้วถือยาว |
| `IM` | **Inverse** | เคลื่อนไหว **ตรงข้าม** ผลตอบแทนรายวันของดัชนี |
| `LM` | **Leveraged** | **ทวีคูณ** ผลตอบแทนรายวันของดัชนี |
| `AN` `PN` `IN` `LN` | [[Feeder Fund\|Feeder]] | ตามกองหลักซึ่งเป็น active / passive / inverse / leveraged |
| `OT` | อื่น ๆ | — |

---

## Active vs Passive — วัดกันอย่างไร

| | Active (`AM`) | Passive (`PM`) |
|---|---|---|
| เป้าหมาย | ชนะดัชนี | ตามดัชนีให้ใกล้ที่สุด |
| ค่าธรรมเนียม | สูงกว่า | ต่ำกว่า |
| ตัวชี้วัดที่ควรดู | **Alpha** (ส่วนเกินจากดัชนี) | **Tracking Error** (ยิ่งต่ำยิ่งดี) |

## ⚠️ Leveraged / Inverse — ระวังการทบต้นรายวัน

> [!CAUTION]
> `LM` และ `IM` การันตีผลตอบแทนตาม **รายวัน** เท่านั้น
> ถือยาวข้ามวันจะเกิด **volatility decay** — ผลลัพธ์ระยะยาวอาจต่างจากที่คาดอย่างมาก
> แม้ดัชนีจะกลับมาที่เดิม
>
> ตัวอย่าง: ดัชนี +10% แล้ว −9.09% กลับมาที่เดิมพอดี
> แต่กอง 2x จะได้ +20% แล้ว −18.18% รวมเป็น **−1.8%** ขาดทุน
>
> กองประเภทนี้ออกแบบสำหรับการเทรดระยะสั้น ไม่ใช่การลงทุนระยะยาว
