# 🧩 ชนิดหน่วยลงทุน (Share Class)

[[00-home|🏠 Home]] · [[../../docs/guides/fund-identifiers|Fund Identifiers]]

---

กองทุนโครงการเดียว (`proj_id` เดียว) สามารถออกหน่วยลงทุนได้หลาย **ชนิด (class)**
ที่ลงทุนในพอร์ตเดียวกัน แต่มีเงื่อนไขต่างกัน

```
โครงการ (proj_id = M0123_2560)
 ├── class "K-XXX-A"    ค่าธรรมเนียมมาตรฐาน, สะสมมูลค่า
 ├── class "K-XXX-D"    จ่ายปันผล
 ├── class "K-XXX-SSF"  ได้สิทธิภาษี SSF
 └── class "K-XXX-I"    สำหรับผู้ลงทุนสถาบัน ค่าธรรมเนียมต่ำกว่า
```

ถ้ากองไม่มี multi-class จะมี class เดียวชื่อ `main`

---

## สิ่งที่ต่างกันได้ระหว่าง class

| ต่างกันได้ | ต่างกันไม่ได้ |
|---|---|
| [[ค่าธรรมเนียมกองทุนรวม\|ค่าธรรมเนียม]] | พอร์ตการลงทุน |
| นโยบายปันผล (สะสม หรือ จ่าย) | [[ระดับความเสี่ยงกองทุนรวม\|ระดับความเสี่ยง]] |
| [[สิทธิประโยชน์ทางภาษีของกองทุนรวม\|สิทธิภาษี]] | ผู้จัดการกองทุน |
| ยอดลงทุนขั้นต่ำ | ดัชนีชี้วัด |
| กลุ่มผู้ลงทุนที่เสนอขาย | |
| [[NAV และราคาซื้อขายหน่วยลงทุน\|NAV ต่อหน่วย]] | |

> [!NOTE]
> NAV ต่อหน่วยต่างกันได้เพราะค่าธรรมเนียมต่างกัน แม้พอร์ตจะเหมือนกันทุกประการ

---

## ผลต่อการอ่านข้อมูล

> [!WARNING]
> ข้อมูลบางชุดเป็น **ระดับ class** บางชุดเป็น **ระดับโครงการ**
>
> **ระดับ class** — ค่าธรรมเนียม, ผลการดำเนินงาน, สถิติ, นโยบายปันผล, NAV, ยอดขั้นต่ำ
> **ระดับโครงการ** — ระดับความเสี่ยง, ดัชนีชี้วัด, การจัดสรรสินทรัพย์, Top 5, พอร์ต, ผู้เกี่ยวข้อง
>
> ตารางเต็มอยู่ที่ [[../../docs/guides/fund-identifiers|Fund Identifiers]]

ในคลังนี้ ตัวเลขระดับ class จะมีคอลัมน์ `Class` กำกับเสมอ

---

## ตัวย่อที่พบบ่อย

| ตัวย่อ | มักหมายถึง |
|---|---|
| `-A` | Accumulation — สะสมมูลค่า ไม่จ่ายปันผล |
| `-D` / `-R` | Dividend — จ่ายปันผล |
| `-I` | Institutional — ผู้ลงทุนสถาบัน |
| `-SSF` / `-RMF` / `-ThaiESG` | class ที่ได้สิทธิภาษี |
| `-H` / `-UH` | Hedged / Unhedged (ป้องกันความเสี่ยงอัตราแลกเปลี่ยน) |

> [!NOTE]
> ตัวย่อเหล่านี้เป็นธรรมเนียมของแต่ละ บลจ. **ไม่ใช่มาตรฐานบังคับ**
> อ่าน `fund_class_detail` และ `fund_class_description` ประกอบเสมอ

## ⚠️ กับดักสำคัญ: ค่าธรรมเนียมต่างกันคนละโลกในกองเดียวกัน

ชนิดหน่วยลงทุนของกองเดียวกัน **ไม่ได้เก็บค่าธรรมเนียมเท่ากัน**
และส่วนต่างมักไม่ใช่เศษเสี้ยว

| กองทุน | ชนิดถูกสุด | ชนิดแพงสุด | ส่วนต่าง |
|---|---|---|---|
| [[../Funds/PRINCIPAL VTOPP\|PRINCIPAL VTOPP]] | 0.21% | 2.47% | **2.26%** |
| [[../Funds/PRINCIPAL GOPP\|PRINCIPAL GOPP]] | 0.01% | 2.19% | **2.18%** |
| [[../Funds/SCBLT3FUND\|SCBLT3FUND]] | 0.10% | 2.24% | **2.14%** |
| [[../Funds/KKP DIVIDEND FUND\|KKP DIVIDEND FUND]] | 0.15% | 2.29% | **2.14%** |

**259 กองรายงานหลายค่า · 85 กองต่างกันเกิน 1%**

### ทำไมจึงต่างกันขนาดนั้น

ชนิดที่ถูกกว่ามาก มักเป็น **ชนิดผู้ลงทุนสถาบัน / กลุ่มบุคคล / ผู้ลงทุนพิเศษ**
ซึ่งขายให้กองทุนสำรองเลี้ยงชีพ กองทุนส่วนบุคคล หรือกองทุนของ บลจ. อื่น
**บุคคลทั่วไปซื้อไม่ได้**

> [!IMPORTANT] สิ่งที่ต้องเช็คก่อนดูตัวเลขค่าธรรมเนียม
> ถามเสมอว่า **"อัตรานี้เป็นของชนิดไหน และฉันซื้อชนิดนั้นได้จริงไหม"**
>
> ในโน้ตกองทุน หัวข้อ **5. ค่าธรรมเนียม → สรุปต่อชนิดหน่วยลงทุน**
> มีคอลัมน์ "ซื้อได้โดย" กำกับทุกชนิด
>
> 🟢 รายย่อยซื้อได้ · 🔒 สถาบัน/กลุ่มบุคคล · 🛡️ ควบกรมธรรม์ · ⚪ ไม่ระบุ

### ผลต่อ [[../Indexes/compare-fees|ตารางเทียบค่าธรรมเนียม]]

ตารางจัดอันดับด้วย **อัตราของชนิดที่ถูกที่สุดซึ่งรายย่อยซื้อได้จริง**เท่านั้น
ถ้าจัดอันดับด้วยค่าต่ำสุดข้ามทุกชนิด จะมี **68 กองติดอันดับผิด**
และ **37 กองผิดเกิน 1%** — PRINCIPAL GOPP จะขึ้นเป็น 0.01% ทั้งที่รายย่อยจ่าย 2.19%

**83 กอง**มีชนิดถูกสุดเป็นชนิดที่รายย่อยซื้อไม่ได้ โน้ตของกองเหล่านี้จะขึ้นคำเตือนไว้

## ⚠️ สองสัญลักษณ์ที่ต้องรู้จัก

### ⚠️ ตัวเลขที่เป็นไปไม่ได้

**46 ชนิดใน 32 กอง** รายงานค่าธรรมเนียมรวม**ที่เก็บจริง**
ต่ำกว่าค่าธรรมเนียมการจัดการ**ที่เก็บจริง** ซึ่งเป็นไปไม่ได้
เพราะค่าจัดการเป็นส่วนหนึ่งของค่ารวม

ตัวเลขเหล่านั้น**ไม่ถูกนำไปใช้จัดอันดับ**

### ℹ️ รายงานไม่ครบ

**262 ชนิด** รายงานค่าธรรมเนียมรวมที่เก็บจริงไว้
แต่**ไม่ได้รายงานค่าธรรมเนียมการจัดการที่เก็บจริง**
เช่น K-FIXED-Z รายงานรวม 0.06% ขณะที่เพดานค่าจัดการคือ 0.54%

เป็นได้สองอย่างและข้อมูล ก.ล.ต. แยกไม่ออก
1. ยกเว้นค่าธรรมเนียมจริงในรอบนั้น
2. เป็นชนิดที่เพิ่งเปิด รายงานไม่เต็มรอบปี

> [!IMPORTANT]
> **215 กอง**มีอัตราถูกสุดที่รายย่อยซื้อได้เป็นตัวเลขแบบนี้
> จึงยังนำไปจัดอันดับ แต่ติดป้าย ℹ️ ไว้ทุกที่
> และตารางแสดง**คอลัมน์เพดาน**ข้างกันเสมอ ให้เทียบเองได้

---

## เก็บจริง vs เพดาน — ห้ามปนกัน

ค่าธรรมเนียมทุกรายการมีสองตัวเลข

| | ความหมาย |
|---|---|
| **เก็บจริง** (`actual`) | อัตราที่เรียกเก็บในรอบที่รายงาน |
| **เพดาน** (`rate`) | อัตราสูงสุดที่หนังสือชี้ชวนอนุญาต |

เพดานมักสูงกว่าที่เก็บจริงมาก — PRINCIPAL GOPP เพดาน **5.35%** เก็บจริง **2.19%**

> [!WARNING]
> **เทียบสองค่านี้ข้ามกันไม่ได้เด็ดขาด**
> การเทียบ "ค่ารวมที่เก็บจริง" กับ "ค่าจัดการเพดาน" เคยทำให้คลังนี้
> สรุปผิดว่ามีข้อมูลเสียหาย 308 รายการ ทั้งที่จริงมี 46 —
> ดู [[../../docs/project/issues|ISS-021]]
