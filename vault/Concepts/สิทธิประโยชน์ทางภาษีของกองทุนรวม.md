# 🧾 สิทธิประโยชน์ทางภาษี

---

## ประเภทที่ API ระบุไว้ (`fund_class_tax_incentive_type`)

| ค่า | ชื่อย่อ |
|---|---|
| `กองทุนรวมเพื่อการออม (Super Savings Fund : SSF)` | **SSF** |
| `กองทุนรวมไทยเพื่อความยั่งยืน (Thailand ESG Fund : Thai ESG)` | **Thai ESG** |
| ค่าว่าง | ไม่มีสิทธิประโยชน์พิเศษ |

> [!IMPORTANT]
> **RMF ไม่มีในรายการนี้**
> API ไม่ได้ให้ flag แยกสำหรับ RMF — คลังนี้จึงตรวจจับจากชื่อย่อกองทุน
> ที่มีคำว่า `RMF` แล้วติด tag `#tax/rmf`
> วิธีนี้เป็น heuristic **อาจพลาดได้** ดู [[../../docs/project/data-quality|Data Quality]]

## สิทธิภาษีเป็นคุณสมบัติของ **share class** ไม่ใช่ของกองทุนทั้งโครงการ

โครงการเดียวกันอาจมีทั้ง class ที่ได้สิทธิ SSF และ class ปกติ
ในโน้ตกองทุน ให้ดูคอลัมน์ "สิทธิประโยชน์ภาษี" ในตาราง
[[ชนิดหน่วยลงทุน Share Class|ชนิดหน่วยลงทุน]]

## เงื่อนไขโดยสรุป

> [!WARNING]
> ข้อมูลด้านล่างเป็น**ภาพรวมเพื่อความเข้าใจ** ไม่ใช่คำแนะนำทางภาษี
> เงื่อนไขเปลี่ยนตามประกาศกรมสรรพากรแต่ละปี — ตรวจสอบกับแหล่งทางการเสมอ

| | SSF | RMF | Thai ESG |
|---|---|---|---|
| ระยะเวลาถือ | 10 ปีนับจากวันซื้อแต่ละครั้ง | ถือถึงอายุ 55 ปี และลงทุนต่อเนื่อง | ตามเงื่อนไขที่ประกาศ |
| ลงทุนใน | สินทรัพย์ใดก็ได้ | สินทรัพย์ใดก็ได้ | สินทรัพย์ไทยที่มีคุณสมบัติ ESG |
| บังคับซื้อต่อเนื่อง | ไม่บังคับ | บังคับ | ตามประกาศ |
