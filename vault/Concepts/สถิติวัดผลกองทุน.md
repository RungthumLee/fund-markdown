## ตัวเลขที่ API ให้มา

| Field | ชื่อไทย | อ่านอย่างไร |
|---|---|---|
| `sharpe_ratio` | Sharpe Ratio | ผลตอบแทนส่วนเกินต่อ 1 หน่วยความเสี่ยง — **ยิ่งสูงยิ่งดี** (เกิน 1 ถือว่าดี) |
| `alpha` | Alpha | ผลตอบแทนส่วนเกินจากดัชนีชี้วัด — บวก = ผู้จัดการสร้างมูลค่าได้ |
| `beta` | Beta | ความไวต่อการเคลื่อนไหวของตลาด — 1 = ตามตลาด, เกิน 1 = ผันผวนกว่าตลาด |
| `maximum_drawdown` | Maximum Drawdown | **ขาดทุนสูงสุด** จากจุดสูงสุดถึงจุดต่ำสุด — ตัวเลขความเจ็บที่แท้จริง |
| `tracking_error` | Tracking Error | ความเบี่ยงเบนจากดัชนี — สำคัญกับกอง [[กลยุทธ์การบริหารกองทุน\|passive]] ยิ่งต่ำยิ่งดี |
| `portfolio_turnover_ratio` | Portfolio Turnover | อัตราการหมุนเวียนพอร์ต — สูง = ซื้อขายบ่อย = ต้นทุนแฝงสูง |
| `recovering_period` | Recovering Period | ระยะเวลาที่ใช้ฟื้นตัวกลับจุดเดิม |
| `portfolio_duration_period` | Duration | อายุเฉลี่ยตราสารหนี้ — ยิ่งยาวยิ่งไวต่อการเปลี่ยนแปลงดอกเบี้ย |
| `fx_hedging` | FX Hedging | สัดส่วนที่ป้องกันความเสี่ยงอัตราแลกเปลี่ยน |

## ตัวไหนควรดูสำหรับกองประเภทไหน

| ประเภทกอง | ดูตัวนี้ก่อน |
|---|---|
| กอง Active หุ้น | Alpha, Sharpe, Max Drawdown |
| กอง Passive / ETF | **Tracking Error**, TER |
| กองตราสารหนี้ | **Duration**, เครดิตของตราสาร |
| กองผสม | Sharpe, Max Drawdown, Beta |
| [[Feeder Fund]] | ดูสถิติของกองหลักประกอบด้วย |

## ข้อควรระวัง

> [!WARNING]
> - **ผลตอบแทนในอดีตไม่รับประกันอนาคต** — คำเตือนมาตรฐานที่มีเหตุผลรองรับจริง
> - ตัวเลขทั้งหมดคำนวณจากงวด factsheet ล่าสุด ไม่ใช่ค่าปัจจุบันแบบเรียลไทม์
> - Sharpe / Alpha / Beta เทียบกันได้เฉพาะกองที่ใช้ **ดัชนีชี้วัดเดียวกัน**
> - ผลตอบแทนที่รายงานเป็น **หลังหักค่าธรรมเนียม** แล้ว — ดู [[ค่าธรรมเนียมกองทุนรวม]]
> - กองที่ตั้งใหม่ (อายุน้อยกว่า 1 ปี) มักไม่มีสถิติเหล่านี้

## Performance types

field `performance_type_desc` ระบุว่าตัวเลขนั้นเป็นผลตอบแทนของ **กองทุน**
หรือของ **ดัชนีชี้วัด** — ต้องดูคู่กันเสมอจึงจะตีความได้

ส่วน `reference_period` คือช่วงเวลา (3 เดือน / 6 เดือน / 1 ปี / 3 ปี / 5 ปี / ตั้งแต่จัดตั้ง)
