## 3. นโยบายการลงทุน

1.นโยบายการลงทุน
ส่วนที่ 1 : กองทุนมีนโยบายที่เน้นลงทุนในหรือมีไว้ซึ่งหุ้นที่เป็นหลักทรัพย์จดทะเบียนในตลาดหลักทรัพย์แห่งประเทศไทย (SET) บนกระดานหลัก หรือกระดานเอ็มเอไอ (mai) ของบริษัทที่มีประวัติการจ่ายปันผลดี สม่ำเสมอ หรือมีแนวโน้มจ่ายเงินปันผลดีในอนาคต โดยพิจารณาจากประวัติการจ่ายปันผลในอดีตในระดับสูง (ประมาณ 1-3 ปีย้อนหลัง) หรือมีแนวโน้มและคาดการณ์การจ่ายปันผลในอนาคตที่ดี ทั้งนี้ กองทุนจะมี net exposure ในหุ้นที่มีลักษณะการจ่ายเงินปันผลตามข้างต้น รวมทั้งมีลักษณะอย่างใดอย่างหนึ่ง หรือหลายอย่าง ดังนี้ โดยรวมกันโดยเฉลี่ยในรอบปีบัญชีไม่น้อยกว่าร้อยละ 80 ของมูลค่าทรัพย์สินสุทธิของกองทุน
 
1) ได้รับการคัดเลือกจาก SET ว่ามีความโดดเด่นด้านสิ่งแวดล้อม (Environment) หรือด้านความยั่งยืน (Environmental, Social and Governance: ESG) โดยผ่านการคัดเลือกและได้รับการประกาศผลประเมินหุ้นยั่งยืน SET ESG Ratings ของตลาดหลักทรัพย์แห่งประเทศไทย ในระดับตั้งแต่ AA ขึ้นไป หรือ
2) มีการเปิดเผยข้อมูลเกี่ยวกับการปล่อยก๊าซเรือนกระจก แผนการจัดการ และการตั้งเป้าหมายเพื่อให้บรรลุเป้าหมายในการลดปริมาณการปล่อยก๊าซเรือนกระจกของประเทศไทย รวมทั้งจัดให้มีการทวนสอบการจัดทำคาร์บอนฟุตพริ้นท์โดยผู้ทวนสอบที่สำนักงานคณะกรรมการ ก.ล.ต. ยอมรับ หรือ
3) มีธรรมาภิบาลในระดับดีเลิศ และมีลักษณะดังนี้
3.1) ได้รับการประเมินการกำกับดูแลกิจการบริษัทจดทะเบียน (Corporate Governance Report of Thai Listed Companies: CGR) จากสมาคมส่งเสริมสถาบันกรรมการบริษัทไทย (Thai Institute of Directors: IOD) ตั้งแต่ 90 คะแนนขึ้นไป หรือเทียบเท่า
3.2) มีการเปิดเผยเป้าหมายและแผนในเรื่องดังนี้ และรายงานความคืบหน้าการปฏิบัติตามเป้าหมายหรือแผน ผ่านช่องทางของ SET ซึ่งจัดไว้สำหรับการเปิดเผยข้อมูลดังกล่าวโดยเฉพาะ
(3.2.1) การมีเป้าหมายและแผนธุรกิจที่เกี่ยวข้องกับการเพิ่มมูลค่าของกิจการ (corporate value up plan)
(3.2.2) การมีเป้าหมายและแผนการยกระดับการดำเนินงาน ในเรื่องใดเรื่องหนึ่ง ดังนี้
 (ก) แผนดำเนินการที่ชัดเจนเพื่อเข้ารับการประเมินจากผู้ประเมินผลการดำเนินงานด้านความยั่งยืนตามมาตรฐานสากลตามข้อ 1)
 (ข) เป้าหมายและแผนดำเนินการเพื่อลดปริมาณการปล่อยก๊าซเรือนกระจกของประเทศไทยตามข้อ 2)
3.3 มีการเพิ่มประสิทธิภาพการสื่อสารกับผู้ลงทุน ตามที่ SET กำหนด
ในกรณีที่ตลาดหลักทรัพย์แห่งประเทศไทยมีการเปลี่ยนแปลงการจัดทำ หรือไม่จัดทำและประกาศผลประเมินหุ้นยั่งยืน SET ESG Ratings ซึ่งอาจส่งผลให้บริษัทจัดการต้องใช้เกณฑ์การคัดเลือกและการประเมินหุ้นยั่งยืนของผู้ประเมินผลการดำเนินงานด้านความยั่งยืนตามหลักสากล (ผู้ประเมินฯ) รายอื่นแทนตลาดหลักทรัพย์แห่งประเทศไทย บริษัทจัดการขอสงวนสิทธิในการเปลี่ยนแปลงผู้จัดทำการคัดเลือกและการประเมินหุ้นยั่งยืน SET ESG Ratings รวมถึงการเปลี่ยนแปลงระดับ Rating ให้อยู่ในระดับที่เทียบเคียงกับนโยบายเดิม โดยจะยึดถือผลประโยชน์สูงสุดของกองทุนและผู้ถือหน่วยลงทุนเป็นสำคัญ ทั้งนี้ บริษัทจัดการจะดำเนินการแก้ไขโครงการตามแนวทางประกาศที่สำนักงาน ก.ล.ต.กำหนด
อย่างไรก็ตาม บริษัทจัดการขอสงวนสิทธิในการเลิกกองทุน ในกรณีที่มีการยกเลิกการใช้หรือไม่มีการคํานวณ ประเมิน SET ESG Ratings ของตลาดหลักทรัพย์แห่งประเทศไทย หรือเกิดเหตุการณ์ที่ทำให้บริษัทจัดการไม่สามารถคัดเลือกหลักทรัพย์ที่เข้าเกณฑ์ลงทุนของบริษัทได้ หรือหากบริษัทจัดการเห็นว่าไม่สามารถลงทุนให้เป็นไปตามวัตถุประสงค์และนโยบายการลงทุนของกองทุน หรือในกรณีที่เกิดสภาวการณ์ที่ไม่ปกติ หรือ กรณีอื่นใดที่เกิดจากปัจจัยที่ควบคุมไม่ได้ โดยจะคำนึงถึงผลประโยชน์ของผู้ถือหน่วยลงทุนเป็นสำคัญ 
ทั้งนี้ เมื่อเกิดเหตุการณ์เลิกกองทุนตามเหตุการณ์ข้างต้น บริษัทจัดการจะดำเนินการสับเปลี่ยนหน่วยลงทุน (การโอนย้ายการลงทุน) ระหว่างกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ รวมถึงหน่วยลงทุนชนิดต่าง ๆ ของกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ ไปยัง กองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ รวมถึงหน่วยลงทุนชนิดต่าง ๆ ของกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ ที่มีนโยบายการลงทุนหรือความเสี่ยงที่ใกล้เคียงกับกองทุนรวมเดิม ภายใต้การจัดการของบริษัทจัดการก่อน ทั้งนี้ หากไม่มีกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ รวมถึงหน่วยลงทุนชนิดต่าง ๆ ของกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ ภายใต้การจัดการของบริษัทจัดการ บริษัทจัดการขอสงวนสิทธิในการใช้ดุลยพินิจในการโอนย้ายหน่วยลงทุนไปยังกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ รวมถึงหน่วยลงทุนชนิดต่าง ๆ ของกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ ภายใต้การจัดการของบริษัทจัดการอื่น เพื่อมิให้กระทบสิทธิประโยชน์ทางภาษีที่ผู้ถือหน่วยลงทุนพึงได้รับจากการลงทุนในกองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ โ …(ตัดทอน)
