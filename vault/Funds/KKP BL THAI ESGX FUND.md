## 3. นโยบายการลงทุน

1. กองทุนเป็นกองทุนผสมที่มีนโยบายการลงทุนในทรัพย์สินกลุ่มความยั่งยืน อย่างใดอย่างหนึ่งหรือหลายอย่างที่ออกโดยผู้ออกที่เป็นภาครัฐไทยหรือกิจการที่จัดตั้งขึ้นตามกฎหมายไทย ดังต่อไปนี้ ตามที่สำนักงาน ก.ล.ต. กำหนดหรือเห็นชอบให้กองทุนรวมไทยเพื่อความยั่งยืนแบบพิเศษ (Thailand ESG Extra Fund) สามารถลงทุนหรือมีไว้ได้ โดยมีการลงทุนและมี net exposure ในทรัพย์สินดังกล่าวโดยเฉลี่ยในรอบปีบัญชีไม่น้อยกว่าร้อยละ 80 ของมูลค่าทรัพย์สินสุทธิของกองทุน 
1.1 หุ้นอย่างใดอย่างหนึ่ง หรือหลายอย่าง ดังนี้ โดยมีการลงทุนและมี net exposure รวมกันโดยเฉลี่ยรอบปีบัญชี ไม่น้อยกว่าร้อยละ 65 ของมูลค่าทรัพย์สินสุทธิของกองทุน โดยเน้นลงทุนในตราสารทุนที่มีนโยบายหรือมีการจ่ายเงินปันผลอย่างสม่ำเสมอ และ/หรือมีแนวโน้มหรือศักยภาพในการจ่ายเงินปันผลในอนาคต
 (1) หุ้นที่เป็นหลักทรัพย์จดทะเบียนในตลาดหลักทรัพย์แห่งประเทศไทย (SET) บนกระดานหลัก ที่ได้รับการคัดเลือกจาก SET ว่ามีความโดดเด่นด้านสิ่งแวดล้อม (Environment) หรือด้านความยั่งยืน (Environmental, Social and Governance: ESG)
 (2) หุ้นที่เป็นหลักทรัพย์จดทะเบียนใน SET บนกระดานหลัก ที่มีการเปิดเผยข้อมูลเกี่ยวกับการปล่อยก๊าซเรือนกระจก แผนการจัดการ และการตั้งเป้าหมายเพื่อให้บรรลุเป้าหมายในการลดปริมาณการปล่อยก๊าซเรือนกระจกของประเทศไทย รวมทั้งจัดให้มีการทวนสอบการจัดทำคาร์บอนฟุตพริ้นท์โดยผู้ทวนสอบที่สำนักงาน ก.ล.ต. ยอมรับ ทั้งนี้ สำนักงาน ก.ล.ต. อาจประกาศกำหนดแนวทางในการพิจารณาการเปิดเผยข้อมูลดังกล่าว โดยคำนึงถึงระดับการเปิดเผยข้อมูลหรือมาตรฐานสากลเกี่ยวกับการปล่อยก๊าซเรือนกระจกอันเป็นที่ยอมรับประกอบด้วยก็ได้
 (3) หุ้นที่เป็นหลักทรัพย์จดทะเบียนใน SET บนกระดานหลัก ที่มีลักษณะดังนี้
 (3.1) เป็นหุ้นของบริษัทจดทะเบียนที่มีธรรมาภิบาล (Governance) โดยได้รับการประเมินการกำกับดูแลกิจการบริษัทจดทะเบียน (Corporate Governance Report of Thai Listed Companies: CGR) จากสมาคมส่งเสริมสถาบันกรรมการบริษัทไทย ตั้งแต่ 90 คะแนนขึ้นไป หรือเทียบเท่า
 (3.2) มีการเปิดเผยเป้าหมายและแผนในเรื่องดังนี้ และรายงานความคืบหน้าการปฏิบัติตามเป้าหมายหรือแผน ผ่านช่องทางของ SET ซึ่งจัดไว้สำหรับการเปิดเผยข้อมูลดังกล่าวโดยเฉพาะ ทั้งนี้ สำนักงาน ก.ล.ต. อาจประกาศกำหนดรายละเอียดเพิ่มเติมของข้อมูลในแต่ละหัวข้อด้วยก็ได้
 (3.2.1) การมีเป้าหมายและแผนธุรกิจที่เกี่ยวข้องกับการเพิ่มมูลค่าของกิจการ (Corporate Value Up Plan) 
 (3.2.2) การมีเป้าหมายและแผนดำเนินการเพื่อลดปริมาณการปล่อยก๊าซเรือนกระจกของประเทศไทยตาม (2) โดยต้องตั้งเป้าหมายเพื่อดำเนินการให้เป็นไปตามแผนการยกระดับดังกล่าวให้แล้วเสร็จภายใน 2 ปีนับแต่วันที่เปิดเผยเป้าหมายและแผนการยกระดับ
 (3.3) มีการเพิ่มประสิทธิภาพการสื่อสารกับผู้ลงทุน ตามที่ SET กำหนด
1.2 ตราสารหนี้ ทั้งตราสารภาครัฐและ/หรือตราสารหนี้ที่ออกโดยธนาคารพาณิชย์และ/หรือตราสารหนี้ที่ออกโดยบริษัทเอกชน อย่างใดอย่างหนึ่ง หรือหลายอย่าง ดังนี้

 (1.1) กรณีเป็นตราสารเพื่ออนุรักษ์สิ่งแวดล้อมหรือตราสารเพื่อความยั่งยืน ต้องมีการเปิดเผยวัตถุประสงค์การใช้เงินที่ได้จากการระดมทุน (Use Of Proceeds) ว่าเป็นไปเพื่อโครงการที่เกี่ยวข้องกับการอนุรักษ์สิ่งแวดล้อมหรือเพื่อโครงการที่เกี่ยวข้องกับความยั่งยืนของประเทศไทย แล้วแต่กรณี
 (1.2) กรณีเป็นตราสารส่งเสริมความยั่งยืนต้องมีการเปิดเผยข้อมูลเกี่ยวกับการกำหนดตัวชี้วัดและเป้าหมายด้านความยั่งยืนเพื่อส่งเสริมความยั่งยืนของผู้ออกตราสารดังกล่าวในประเทศไทย
 (2) พันธบัตรรัฐบาล พันธบัตรที่กระทรวงการคลังค้ำประกันต้นเงินและดอกเบี้ย หรือหุ้นกู้ที่กระทรวงการคลังค้ำประกันต้นเงินและดอกเบี้ยแต่ไม่รวมถึงหุ้นกู้แปลงสภาพ ซึ่งเป็นพันธบัตรหรือหุ้นกู้เพื่ออนุรักษ์สิ่งแวดล้อม (Green Bond) พันธบัตรหรือหุ้นกู้เพื่อความยั่งยืน (Sustainability Bond) หรือพันธบัตรหรือหุ้นกู้ส่งเสริมความยั่งยืน (Sustainab …(ตัดทอน)
