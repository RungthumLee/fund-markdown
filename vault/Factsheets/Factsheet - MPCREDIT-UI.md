### นโยบายและกลยุทธ์การลงทุน (ฉบับย่อจาก factsheet)

ลงทุนในหนวยลงทุนของกองทุนรวมตางประเทศเพียงกองทุนเดียว (Feeder Fund) คือ Apollo Debt Solutions BDC iCapital Offshore Access Fund SPC (กองทุนหลัก) ชนิดหนวยลงทุน Class C-I-Dis ในสกุลเงินดอลลาร สหรัฐ (USD) โดยเฉลี่ยในรอบปบัญชีไมนอยกวารอยละ 80 ของ NAV ซึ่งกองทุนหลักจดทะเบียนจัดตั้งภายใต กฎหมายของหมูเกาะเคยแมน (the Cayman Islands) และมี iCapital Advisors, LLC เปนผูบริหารการลงทุน กองทุนหลักจะนําทรัพยสินเกือบทั้งหมดไปลงทุนในกองทุน Apollo Debt Solutions BDC (กองทุนอางอิง) ชนิดหนวยลงทุน Class I ในสกุลเงินดอลลารสหรัฐ (USD) ซึ่งกองทุนอางอิงมีสถานะเปนกองทรัสตตามกฎหมาย
